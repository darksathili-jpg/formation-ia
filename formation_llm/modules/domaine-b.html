03

Embeddings et similarité cosinus

Comprendre qu’un vecteur n’est ni un ID ni une vérité, et qu’un score de similarité n’est pas une probabilité.

Laboratoire vectoriel

Les vecteurs ci-dessous sont volontairement en 3 dimensions pour être manipulables. Les embeddings réels sont généralement de dimension bien supérieure.

0.000
cosinus
Question difficile. « 0,90 = 90 % de même sens ? » Réponse : non. Le cosinus est une relation géométrique dans un espace donné ; sa calibration dépend du modèle et de la tâche.

Trois distinctions à verrouiller

ID de token ≠ embeddingL’ID est un index discret. L’embedding est un vecteur utilisé dans les calculs.
Embedding de token ≠ embedding de phraseUn modèle peut représenter les tokens en entrée et un autre système produire un seul vecteur pour une phrase ou un document.
Similarité ≠ véritéDeux textes peuvent être proches vectoriellement et pourtant différer sur une négation, un nombre ou un fait décisif.

Les 12 notions du Domaine B

Chaque carte contient la formulation minimale à savoir défendre face à un participant.

B01

Corpus d’entraînement

Ensemble de données utilisées pendant l’apprentissage. Le corpus n’est pas la mémoire de contexte d’une conversation.

Piège : croire que le modèle consulte directement ses documents d’entraînement lors de chaque réponse.
B02

Token

Unité discrète du vocabulaire du tokenizer : mot, sous-mot, signe, espace encodé, octet ou marqueur spécial.

Piège : « token = mot ».
B03

Tokenisation

Transformation d’une entrée en séquence de tokens selon les règles d’un tokenizer donné.

Piège : croire à un simple découpage sur les espaces.
B04

Vocabulaire

Ensemble fini d’unités que le tokenizer sait associer à des identifiants.

Piège : confondre vocabulaire et connaissances.
B05

Sous-mots / BPE

Famille d’approches qui compose des unités fréquentes afin d’éviter un vocabulaire contenant tous les mots possibles.

Piège : présenter BPE comme l’unique tokenizer moderne.
B06

ID de token

Entier servant d’index. Sa proximité numérique n’implique aucune proximité de sens.

Piège : interpréter la valeur de l’ID.
B07

Token spécial

Unité réservée à une fonction de structure : rôle, séparation, début/fin, remplissage… selon le modèle.

Piège : supposer que tous les modèles utilisent les mêmes marqueurs.
B08

Embedding

Vecteur représentant une unité ou un objet pour permettre les calculs neuronaux.

Piège : réduire l’embedding à « l’ID avec plusieurs nombres ».
B09

Espace vectoriel

Espace mathématique de grande dimension où distances, angles et voisinages peuvent être étudiés.

Piège : prendre une projection 2D pour une carte fidèle de l’espace réel.
B10

Embedding sémantique

Vecteur conçu pour rapprocher des textes semblables selon une notion apprise de similarité.

Piège : parler d’une représentation parfaite du sens.
B11

Similarité cosinus

Mesure fondée sur l’angle entre deux vecteurs. Utile pour comparer des embeddings.

Piège : lire le score comme un pourcentage de vérité.
B12

Fenêtre de contexte

Budget de séquence disponible pour le traitement courant, généralement exprimé en tokens.

Piège : confondre grande fenêtre et mémoire parfaite.
06

Test de maîtrise formateur

Objectif : être capable de corriger les simplifications trompeuses, pas seulement de réciter les définitions.

1. Un token est…
Un token est une unité discrète définie par le tokenizer ; il peut être un sous-mot, un signe, etc.
2. Deux IDs de tokens 1200 et 1201…
L’ID sert d’index ; sa valeur numérique n’est pas une coordonnée sémantique.
3. Un embedding de token est…
L’embedding fournit une représentation vectorielle utilisable par le réseau.
4. Une similarité cosinus de 0,92 signifie…
Le cosinus est géométrique ; il n’est ni une probabilité ni un certificat de vérité.
5. Une fenêtre de contexte plus grande garantit…
Capacité d’entrée et qualité d’utilisation de l’information sont deux questions différentes.
6. BPE est…
Il existe d’autres familles et de nombreuses variantes ; il faut parler du tokenizer concret du modèle étudié.
7. La mémoire d’une application de chat…
Une mémoire applicative peut être stockée ailleurs puis sélectionnée, résumée ou réinjectée.
8. Dans ce laboratoire, les embeddings affichés sont…
Le laboratoire est volontairement autonome et distingue simulation pédagogique et comportement d’un modèle réel.
