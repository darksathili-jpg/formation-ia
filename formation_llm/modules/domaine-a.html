Parcours 0 · Fondamentaux · PILOTE NOVICE-FIRST V2

Comprendre ce qui se cache derrière un assistant IA

On ne commence plus par douze définitions. Vous allez d'abord faire des choix, modifier un système et observer ce qui change. Les mots techniques arriveront seulement lorsqu'ils deviennent utiles.

Manipulation-first≈ 45–60 minAucun prérequis technique
Question fil rouge

Quand un assistant répond, retrouve un document, se souvient d'un prénom ou ouvre un calendrier : est-ce vraiment le LLM qui fait tout cela ?

Point de départ
Aucune connaissance IA requise

Vous connaissez déjà des applications, des fichiers et des services web : cela suffit.

Méthode
Faire avant de nommer

Chaque notion centrale naît d'une prédiction, d'une action et d'un résultat observable.

Réussite
Expliquer d'où vient une capacité

Vous saurez distinguer modèle, application, mémoire, recherche et outil dans un système inconnu.

01

Premier défi — qui fait réellement quoi ?

Répondez avant toute définition. Le but est de révéler votre intuition de départ.

Assistant scolaire fictif

Imaginez un chat qui utilise un modèle de langage. Pour chaque capacité, choisissez l'explication la plus plausible. Vous pourrez vous tromper : le feedback sert précisément à construire la distinction.

Rédiger une reformulation

L'assistant reformule un paragraphe déjà présent dans la conversation.

Retrouver le règlement actuel

Le règlement a été modifié hier et n'apparaît pas dans la conversation.

Se souvenir demain du prénom

La conversation est fermée puis rouverte le lendemain.

Créer un événement calendrier

L'assistant ajoute réellement un rendez-vous dans un agenda.

À observer. Ne corriger aucun vocabulaire avant le clic. Demander ensuite : « Quelles capacités semblent appartenir au générateur de texte, et lesquelles exigent quelque chose autour ? »
02

Mettons quatre noms sur ce que vous venez d'observer

Seulement les mots nécessaires pour comprendre le défi précédent.

NIVEAU 1

Application

Le produit complet utilisé par une personne. Il peut assembler interface, modèle, mémoire, documents, outils et règles.

NIVEAU 2

Modèle

Un composant appris qui transforme des entrées en sorties. Ici, il produit notamment du langage.

TYPE DE MODÈLE

LLM

Large Language Model : grand modèle de langage neuronal. Un LLM peut être le moteur linguistique d'une application sans être toute l'application.

AUTOUR DU MODÈLE

Composant externe

Mémoire, recherche documentaire ou outil appelé par l'application. Ces composants peuvent donner des capacités que les poids du modèle n'offrent pas seuls.

Phrase repère : « Le LLM produit et transforme du langage ; l'application décide aussi de ce qu'elle lui donne et de ce qu'elle l'autorise à utiliser. »
03

Exemple travaillé — expliquer une capacité sans magie

On reprend une seule situation et on déroule le raisonnement.

1

Observation

« L'assistant cite le règlement intérieur modifié hier. »

Question : cette information était-elle déjà fournie dans la conversation ? Non.
2

Ce que le LLM peut faire

Le modèle peut lire un passage qu'on lui fournit et rédiger une réponse à partir de ce passage.

Mais : cela ne prouve pas qu'il possède spontanément la version d'hier.
3

Ce qu'il faut autour

L'application doit retrouver le document actuel puis placer l'extrait utile dans le contexte envoyé au modèle.

Nom utile : recherche documentaire / retrieval ; lorsqu'elle alimente une génération, on parle souvent de RAG.
4

Conclusion

La réponse finale est produite par le modèle, mais l'accès au document actuel vient d'un composant de l'application.

Erreur évitée : « le LLM contient le règlement en temps réel ».

06

Family Lab — où placer un LLM dans l'IA ?

Construisez la chaîne du plus large au plus spécifique avant de lire l'explication.

1 · le champ le plus large
2 · une famille de méthodes
3 · une sous-famille neuronale
4 · un type de modèle de langage
Après vérification : IA → machine learning → deep learning → LLM. Cette chaîne situe les LLM modernes ; elle ne signifie pas que toute l'IA utilise du machine learning.
Approfondir seulement si vous êtes à l'aise : 8 repères supplémentaires
IA

Champ très large regroupant des systèmes capables de produire décisions, contenus ou actions.

Machine learning

Méthodes où le comportement d'un modèle est ajusté à partir de données.

Deep learning

Machine learning utilisant des réseaux neuronaux profonds.

TAL / NLP

Domaine du traitement informatique du langage.

IA générative

Systèmes conçus pour produire de nouveaux contenus, pas seulement du texte.

Modèle de langage

Modèle attribuant des scores ou probabilités à des séquences ou continuations.

LLM

Grand modèle de langage neuronal ; tous les modèles de langage ne sont pas des LLM modernes.

Foundation model

Modèle de grande échelle réutilisable pour de nombreuses tâches ; catégorie plus large que LLM.

GPAI

Catégorie juridique européenne concernant certains modèles d'IA à usage général.

Modèle ≠ chatbot ≠ application

Le modèle est un composant appris ; l'application assemble plusieurs briques.

Paramètres / poids

Valeurs numériques apprises ; pas une bibliothèque de documents adressables.

Open weights / open source

Poids accessibles et open source ne sont pas des synonymes ; la licence et les éléments fournis comptent.

07

Quatre pièges à mettre en défaut

Relisez-les en cherchant quel micro-lab apporte déjà un contre-exemple.

« Le chatbot = le LLM »

Le produit visible peut ajouter mémoire, recherche et outils.

Test : désactivez ces composants dans le System Builder.
« S'il cite un document actuel, il est dans ses poids »

Le document peut avoir été retrouvé puis injecté au moment de la requête.

Test : mission « règlement modifié aujourd'hui ».
« Se souvenir = apprendre de nouveaux poids »

Une application peut stocker une donnée puis la réinjecter plus tard.

Test : mission « retrouver demain le prénom ».
« Open weights = open source = gratuit »

Accès aux poids, licence, code et prix sont des dimensions différentes.

Correction : préciser exactement ce qui est ouvert et sous quelles conditions.

Reconstruisez le raisonnement, sans recopier une définition.

09

Test de maîtrise — sans remonter la page

Le feedback explique le raisonnement, pas seulement la réponse.

1. Dans un assistant complet, le LLM est généralement…
Le modèle produit ou transforme notamment du langage ; l'application orchestre aussi interface, données, mémoire et outils.
2. Le règlement a changé ce matin. Quel mécanisme permet le plus directement d'utiliser la nouvelle version ?
Une recherche documentaire peut donner au modèle un contexte à jour sans réentraîner ses poids.
3. Une application se souvient demain de votre préférence. Cela prouve que…
La persistance peut être gérée hors du modèle par un stockage applicatif.
4. Quelle chaîne situe correctement un LLM moderne ?
Le LLM moderne est un type de modèle de deep learning ; le deep learning appartient au machine learning, dans le champ plus large de l'IA.
5. Des poids téléchargeables permettent-ils à eux seuls d'affirmer « open source » ?
« Open weights » décrit l'accès aux poids ; le statut open source demande davantage d'informations.
6. « Modèle de langage » et « LLM moderne » sont-ils strictement synonymes ?
LLM désigne une famille moderne de grands modèles neuronaux de langage, pas toute l'histoire des modèles de langage.
10

Transfert — quatre situations nouvelles

Les exemples changent ; le raisonnement reste le même.

Studio créatif

Un site génère des images, garde vos projets et appelle un éditeur externe.

Le produit visible assemble génération, stockage et outil externe.

Musique

Un système produit un morceau audio à partir d'une description.

Produire un nouveau contenu relève du génératif ; rien n'impose un LLM textuel.

Fraude

Un modèle est ajusté sur des transactions passées pour classer de nouvelles opérations.

Le comportement est ajusté à partir de données : c'est du machine learning.

Modèle téléchargeable

Une entreprise publie les poids sous une licence précise mais pas tous les éléments de développement.

L'accès aux poids ne suffit pas à conclure sur tout le statut d'ouverture.
11

Six idées à reconstruire sans réciter

Essayez de retrouver pour chacune le micro-lab qui l'a rendue visible.

1. Le LLM n'est pas toute l'application.

Il est un composant appris au sein d'un système plus large.

2. Une capacité visible a une origine.

Demandez si elle vient du modèle, du contexte, d'une mémoire, d'une recherche ou d'un outil.

3. Une donnée actuelle peut être apportée au modèle.

Recherche documentaire et RAG ne nécessitent pas de modifier les poids à chaque document.

4. Mémoire applicative ≠ apprentissage des poids.

Une donnée persistante peut être stockée puis réinjectée.

5. IA → ML → deep learning → LLM.

Cette chaîne situe les LLM modernes sans réduire toute l'IA au machine learning.

6. « Open » doit être précisé.

Poids, code, licence et gratuité sont des dimensions distinctes.

Pont vers P1. Vous savez maintenant identifier le modèle à l'intérieur du système. La prochaine question sera : comment le texte entre-t-il réellement dans ce modèle ?
