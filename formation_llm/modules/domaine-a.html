Situer les LLM

Avant de manipuler tokens, attention ou RAG, il faut savoir de quoi l’on parle. Ce module construit une carte mentale fiable : IA, machine learning, deep learning, TAL, IA générative, modèles de langage, LLM, foundation models et applications.

La question directrice

Quand un participant dit « l’IA », « ChatGPT », « le modèle » ou « une IA open source », parle-t-il vraiment de la même chose ?

01

Concept Map Lab — carte mentale interactive

La chaîne IA → ML → deep learning → LLM décrit un chemin d’appartenance fréquent pour les LLM modernes. Modèle de langage, TAL, IA générative, foundation model et application sont des notions liées, mais ne forment pas une unique hiérarchie emboîtée.

Question à poser. « Un LLM est-il toute l’IA ? » Attendu : non. Un LLM est un type de modèle de langage neuronal, lui-même situé dans un paysage beaucoup plus large.

03

Classer sans confondre

Choisissez la description la plus précise. Plusieurs objets peuvent appartenir au champ de l’IA, mais le bon niveau de vocabulaire compte.

Cas 1

Filtre anti-spam appris sur des exemples

Il classe les messages après apprentissage à partir de données étiquetées.

C’est un exemple de machine learning ; aucun LLM n’est nécessaire.
Cas 2

Générateur d’images à partir d’un texte

Il produit de nouvelles images conditionnées par une consigne.

C’est de l’IA générative, mais pas nécessairement un LLM.
Cas 3

Modèle neuronal prédisant des continuations textuelles

Il possède une grande capacité et peut être adapté à de nombreuses tâches de langage.

La description vise le modèle lui-même : un LLM.
Cas 4

Assistant qui recherche sur le web et utilise un calendrier

Il combine interface, modèle, contexte et outils externes.

Les outils et la recherche sont des capacités du système applicatif, pas nécessairement du réseau neuronal.
Cas 5

Modèle n-gramme historique

Il attribue des probabilités aux continuations possibles sans réseau profond moderne.

Les modèles de langage existaient avant les LLM modernes.
Cas 6

Analyseur syntaxique

Il identifie les relations grammaticales d’une phrase.

C’est une tâche classique du traitement automatique du langage.
04

Open weights n’est pas un synonyme d’open source

La disponibilité des poids est une information importante, mais elle ne suffit pas à décrire tous les droits et éléments fournis avec un système.

Cas A

API uniquement

poids non fourniscode modèle non fourni

Le modèle est accessible comme service.

Modèle propriétaire / fermé sur ces éléments. L’accès par API ne donne pas accès aux poids.
Cas B

Poids téléchargeables

poids accessibleséléments incomplets

Une licence permet certains usages, mais tout le système de développement n’est pas fourni.

Open weights est la description prudente. « Téléchargeable » ne suffit pas à conclure automatiquement « open source AI ».
Cas C

Éléments largement ouverts

poidscodelicence adaptée

Les éléments nécessaires à l’étude, la modification et la redistribution sont fournis selon les droits annoncés.

Peut relever d’une démarche open source, à apprécier selon la définition et la licence exactes, pas seulement selon la disponibilité des poids.
Cas D

Gratuit mais fermé

usage gratuitpoids non fournis

Le service ne facture pas l’utilisateur, mais le modèle reste inaccessible.

Gratuit ≠ libre. Prix d’accès et degré d’ouverture sont deux dimensions différentes.
Point de vigilance. Éviter de transformer « open source » en simple étiquette marketing. Faire regarder la licence et les éléments réellement fournis.
05

Les 12 notions fondamentales

Le minimum rigoureux à savoir expliquer avant de poursuivre vers tokens et Transformer.

Notion 01

Intelligence artificielle

Champ large de systèmes capables de produire des sorties à partir d’entrées et d’objectifs.

Piège : IA = chatbot.
Notion 02

Machine learning

Méthodes qui apprennent des régularités à partir de données plutôt que d’expliciter toutes les règles.

Piège : ML = toute l’IA.
Notion 03

Deep learning

Famille de ML utilisant des réseaux neuronaux à plusieurs couches et apprenant des représentations.

Piège : « deep » = réflexion profonde.
Notion 04

TAL / NLP

Domaine consacré au traitement informatique du langage humain écrit ou oral.

Piège : TAL apparu avec les chatbots récents.
Notion 05

IA générative

Systèmes conçus pour produire de nouveaux contenus : texte, image, audio, vidéo, code…

Piège : génératif = seulement texte.
Notion 06

Modèle de langage

Modèle attribuant des probabilités à des séquences ou continuations possibles.

Piège : tout modèle de langage est un LLM.
Notion 07

LLM

Modèle de langage neuronal de grande échelle entraîné sur de vastes corpus.

Piège : LLM = chatbot.
Notion 08

Foundation model

Modèle à grande échelle pouvant être adapté à un large éventail de tâches en aval.

Piège : synonyme exact de LLM.
Notion 09

GPAI

Catégorie juridique européenne pour certains modèles d’IA à usage général. Ce n’est pas une taxonomie scientifique universelle.

Piège : GPAI = terme purement technique.
Notion 10

Modèle ≠ chatbot ≠ application

Une application peut ajouter interface, mémoire, recherche, données, instructions et outils autour d’un modèle.

Piège : attribuer au modèle toutes les fonctions du produit.
Notion 11

Paramètres / poids

Valeurs numériques apprises pendant l’entraînement et utilisées dans les transformations du réseau.

Piège : poids = base documentaire consultable.
Notion 12

Open source / open weights

L’accès aux poids, la licence, le code et les éléments fournis doivent être distingués.

Piège : téléchargeable = automatiquement open source.
06

Test de maîtrise

Le passage à l’étape suivante suppose de savoir employer les bons niveaux de vocabulaire.

1. Un LLM est avant tout…
Le LLM est le modèle. Une application peut l’entourer d’interface, RAG, mémoire et outils.
2. Une application de chat recherche sur le web. Cela prouve que…
Une capacité visible dans le produit peut venir du système qui entoure le modèle.
3. Les paramètres d’un modèle sont…
Paramètres et contexte courant sont deux choses différentes.
4. « Open weights » signifie au minimum que…
Il faut examiner séparément poids, code, licence, documentation et autres éléments.
5. GPAI est ici surtout…
Les concepts se recouvrent partiellement, mais une catégorie juridique ne doit pas être confondue avec une taxonomie scientifique.
6. Le TAL / NLP…
Les LLM s’inscrivent dans une histoire beaucoup plus ancienne du traitement automatique du langage.
